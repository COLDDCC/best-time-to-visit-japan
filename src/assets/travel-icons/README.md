# Travel line illustrations

Selected outline SVGs from [Tabler Icons](https://github.com/tabler/tabler-icons/tree/main/icons/outline), maintained by Paweł Kuna and contributors. The original MIT license is included in LICENSE.

Fetched through the GitHub connector on 2026-10-25: jacket, shirt, shoe, umbrella, sun, cloud-rain, snowflake, wind. Original SVG geometry is retained; TravelLineIcon.astro adjusts the display stroke to 1.35 for the larger packing illustrations.

The SVGs are decorative symbols with adjacent text labels. They are rendered directly in the built HTML, with no client icon-library download or API dependency.

TravelLineIcon.astro also contains original code-drawn long-sleeve, full-length coat and winter-boot illustrations, so winter suggestions do not rely on generic T-shirt or sneaker symbols.
