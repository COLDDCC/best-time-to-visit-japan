# 代购团购收集助手（Chrome 插件）

在菌核屋商品页点一下插件图标，自动抓取**商品图片链接、名称、价格**，写进飞书多维表格；
**团员名字这一列插件不填**，留给你在表格里手动核对、填写（同一件商品可能被好几个人下单）。

## 它做了什么

- 打开商品页 → 点插件图标 → 点「抓取本页商品信息」，插件会尝试自动读出图片、名称、当前价格。
- 插件会看**今天是不是周六/周日**（或你在设置里加的法定节假日），自动把抓到的价格填进「平时价」
  还是「周末价」那一栏；抓到的划线原价（如果页面上有）会顺手填进另一栏，供你核对。
- 所有字段在保存前都能手动修改——抓取只是省去打字，不保证 100% 准确，尤其是价格识别依赖页面结构，
  第一次用建议核对一下。
- 点「保存到多维表格」：如果这件商品的链接在表格里已经有记录了，只会**更新价格等字段**（不会新建重复行，
  也不会把已经填好的团员名字覆盖掉）；没有的话才新建一行。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`，右上角打开「开发者模式」。
2. 点「加载已解压的扩展程序」，选中这个 `group-buy-tracker-extension` 文件夹。
3. 插件栏里会出现图标，建议固定住方便点击。

## 准备飞书多维表格

1. 在飞书里新建一个多维表格，建好这几列（列名可以自己改，改了要在插件设置里同步改）：
   - 商品名称（文本）
   - 商品图片链接（文本，或者超链接类型也行）
   - 商品链接（文本/超链接）
   - 平时价（数字）
   - 周末价（数字）
   - 团员（文本，插件不会写这一列，你自己填）
2. 打开这个表格，看地址栏，形如：
   `https://xxx.feishu.cn/base/HrgybwhZAaaaaa?table=tblXXXXXXXXXX`
   `base/` 后面那一段是 `app_token`，`table=` 后面那一段是 `table_id`。

## 创建飞书自建应用（用来调 API 写数据）

1. 打开 [飞书开放平台](https://open.feishu.cn/app)，创建一个「企业自建应用」。
2. 在应用的「权限管理」里开通多维表格相关权限（搜索 bitable / 多维表格，把读写记录相关权限都勾上）。
3. 发布这个应用版本（企业自建应用一般需要管理员在后台审核通过一次）。
4. 回到你的多维表格，右上角「协作者」里，把这个应用添加为协作者（否则应用有权限也进不了这张表）。
5. 在应用详情页找到 **App ID** 和 **App Secret**，填到插件设置里。

## 配置插件

右键插件图标 →「选项」（或点插件弹窗右上角的 ⚙）：

1. 填 App ID / App Secret。
2. 填 app_token / table_id。
3. 核对字段名是否和表格列名完全一致（默认是「商品名称/商品图片链接/商品链接/平时价/周末价」）。
4. 需要的话，补充法定节假日日期。
5. 点「测试连接」，显示「连接成功」就说明配置对了。

## 已知局限 / 可以继续改进的地方

- 图片目前是存**链接**，不是飞书的「附件」类型，所以表格里默认显示的是一串 URL，不是缩略图。
  想要缩略图的话，需要把列改成「附件」类型，插件这边要多做一步「下载图片 → 上传到飞书 → 存
  file_token」，目前没做，先能跑起来记录数据。
- 价格识别是靠页面文字里的 `¥`/`￥`/`元` 加数字、以及有没有「划线价」样式来猜的，不同商品页排版
  不一样，猜不准是正常的，保存前记得看一眼再点保存。
- 「周末/节假日」只按你电脑当前日期判断，不会自动同步法定节假日日历，需要的日期要自己加到设置里。
